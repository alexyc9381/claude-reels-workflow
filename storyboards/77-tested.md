## THE THREE FLOORS (STORYBOARD-SPEC §2) — declared

1. **Every scene is a real place.** Named location + ≥4 depth planes + one light direction + world props, per card.
2. **Camera LOCKED.** ⛔ Zero pushes/pans/zooms anywhere in this reel (`reel-motion-hierarchy` hardened rule). Shot changes are HARD CUTS to a new locked framing. Scene-internal motion = one hero mover at a time, 3–4 sequential events per scene.
3. **Arc shape.** Value-ladder, ordered by ASCENDING value — the fork (S4) is the most surprising tip and lands last, and the crest is the S5 warehouse reveal, not the hook.

**Intensity curve:** `S0 8.0 · S1 7.5 · S2 8.5 · S3 9.0 · S4 8.0 · S5 9.5 · S6 6.5`
Gate: no belly sag (min 7.5, hook 8.0) ✓ · peak 9.5 **beats** the hook ✓ · payoff never spent early ✓ · one dip, late (S4, immediately before the crest) ✓ · no two adjacent drops ✓.

**Inter-scene colour sequence** (`reel-interscene-contrast` — every cut is a hue/value jump):
dark slate-navy **or** plum-ochre (hook, see variants) → **bleached clinical white** → **deep crimson/ember** → **forest green + dusk amber** → **cool teal night** → **dust-gold ochre** → **warm gold blur**.

## ADVERSARIAL CRITIC PASS (STORYBOARD-SPEC §3) — run, and what it changed

- **Swipe points 0–5s.** S0 was originally *"open on the full 50-rack, wide"* — an open-at-maximum frame with no before-state, which is the exact four-times-rejected reel-66 failure. **Rewritten:** all three variants now open on a deliberately ordinary state and break it at ~f20.
- **Repeated base object.** First draft used the crate rack in S0 **and** S5 as the same shot. That is the CALLBACK S1=S2 failure. **Rewritten:** S0 is a tight, cropped fragment of the rack (or, in variants B/C, not the rack at all); S5 is the first and only wide. Additionally B and C remove the repeat entirely — another reason C is the recommended pick.
- **Payoff spent early.** First draft's hook named the four tips on the crate lids. Killed — the hook now shows **numbers only** (`04`, `TESTED`), never a tip name.
- **Belly sag.** First draft ran S1 (booth) and S2-A (door list) back to back as two quiet analysis beats — the "compound exit" CALLBACK's critic flagged. **Rewritten:** S2 is split into two shots with the tripwire SLAM landing at 23s, so there is a hard physical event inside the 15–25s window.
- **Villain integrity.** N/A — no villain (correctly, per the selector).
- **Concept complexity.** Each scene now passes the one-plain-sentence test (written as MUTE TEST on every card). S2 was the risk; splitting it into "the list gets skipped" + "the wire stops you" fixed it.
- **Peak vs hook.** Peak 9.5 > hook 8.0 ✓ — and the peak is a *scale* reveal, which the hook structurally cannot pre-spend.
