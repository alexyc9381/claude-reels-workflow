## §0 — THE HONESTY LINE (settled before a pixel is drawn)

The VO makes **no sourceable third-party claim** — no star count, no price, no benchmark, no
product name but Claude's own. It describes a workflow Alex owns. So the usual failure (drawing a
number nobody checked) cannot happen here. Two different edges still have to be held:

1. ⛔ **NOTHING IN THIS REEL MAINTAINS ITSELF.** The VO says "you can add new notes anytime
   without breaking the system" — the *system* does not break; it does not say the index updates
   itself. **S9 therefore shows a HAND putting the new card in and a HAND adding the line.** No
   scene anywhere draws the index writing its own entry.
2. ⛔ **"SAVE IT DIRECTLY FOR YOU" IS A FILE WRITE, NOT A PUBLISH.** S10 ends in a folder on the
   desk with `SCRIPT.md` stamped on it — a local file. Nothing is drawn uploading, posting or
   sending. The header states the honest mechanism the audio glides over: `IT WRITES TO DISK /
   NOT TO THE CHAT`.

⛔ **"CONTEXT COMPASS" IS ALEX'S OWN NOUN, SPOKEN IN THE RECORDING.** The compass rose is
therefore *literal vocabulary*, not a metaphor the viewer has to decode — the same free ride reel
104 got from "plug in" and reel 100 from Apple's real token names.

## §1 — THE PLACE, AND WHY EVERY PROP IS LITERAL

**THE NOTE ROOM** — a records desk against a floor-to-ceiling card wall. Frame it and say what
each thing IS. ⛔ If the honest answer needs "stands for", it is cut. Every answer here is
literal:

| on screen | what it actually is |
|---|---|
| the wall of ~200 cream cards | your notes. Actual files. Not a symbol of "information" |
| the hooded lamp over the desk | the one committed light source, and the only light in the reel |
| **THE HOPPER** (ceiling intake, funnel, gauge) | the prompt box you paste everything into |
| the segmented arc on its throat | the context window filling |
| the shred tray under its chute | the mush a stuffed prompt gives back |
| the pin board + the real GitHub mark | searching for a template repo |
| the date stamped on each result | why the template is wrong: it is someone else's snapshot |
| **THE COMPASS CARD** on its brass stand | `COMPASS.md`, the one index file |
| the needle taking a bearing | the index resolving a question to a location |
| the beam landing on 3 lit cards | Claude opening three files instead of two hundred |
| the folded brief that stands up | the summary that comes back |
| the wall counter flipping 200 → 201 | adding a note |
| the print carriage + the folder that snaps | Claude writing the script and saving it to disk |

**Depth, every scene, 5 planes** (`SET-AND-LIGHT` §1): ① a foreground mass cropped by the panel
edge — the desk's near lip, the hopper's arm, or a card rack (`Edge`); ② hero — the sprite and the
one hero prop, never blurred; ③ midground — the desk deck, the belt, the stand; ④ background — the
card wall itself; ⑤ far — a warm doorway deep behind the wall, hazed. Atmosphere: paper dust in
the lamp beam (`Motes`, one per scene, never a second mover).

**Light:** ONE direction all reel — **key from the hooded lamp, high and slightly camera-left;
cool rim from the far doorway.** Every object obeys it. The lamp is a real fixture in the set and
it swings when something lands, which is how the room reacts without a second animation.

⛔ **MATTE PALETTE.** Solid paints, dark drop-shadows, shaped cones. **No `0 0 Npx <colour>`
anywhere in this reel** — the grep is a ship gate.

⛔ **THE LOOK BAR IS `docs/ANIMATION-QUALITY.md` §8, NOT THE MOTION AUDIT.** Frame 0 ≥ 140 luma
and **nowhere else**. Body scenes target luma **70-105**, saturated pixels **34-45%**, black point
p10 **≤ 35**. When a set reads dim the fix is a practical light or a brighter subject — ⛔ never
lifting the palette's dark stop, which is the move that washed out ten reels.

## §3 — THE SCENE CARDS

Each card names the **EVENT** as its four parts (`ANIMATION-QUALITY` §2): a *before state* legible
on the first frame, a visible *trigger*, *travel* across distance, and an *arrival that costs
something*. ⛔ Nothing in this reel lands and simply stops.

Every card also answers the §3 test — the VO line is written beside it and the card states **what
the picture ADDS**. If the answer were "it shows there are lots of them", the prop is a container
and is rejected on the board, which is where it is free.
