### S1 · PROBLEM · 5.45-13.3s
- **Takeaway:** It is not your fault. The AI's taste is a rigged slot machine: every pull locks the same three symbols, purple gradient, Inter, centered hero with one button. You cannot out-prompt a fixed machine. Fix the machine, not the pull.
- **Base object:** A rigged LOVABOLT casino slot machine (one-armed bandit) with three visible reels and a big lever. Distinct from every other scene: S0 = purple website-copier machine (the OUTPUT), S1 = slot machine (the CAUSE), no overlap with S2 armor / S6 vault wall.
- **Story / metaphor:** The one-armed bandit. AI's default taste is a slot machine bolted to the LOVABOLT builder, with the reels pre-set by the house. You drop in a coin (your prompt), yank the lever, and the three reels always slam to the SAME three symbols: a purple gradient, an Inter "Aa", a centered hero with one rounded button. Yank harder, feed a fancier coin, does not matter. The gambler is not the problem. The rigged machine is. It only knows one jackpot, and that jackpot is generic AI slop.
- **Why (rejected alt):** The critic's core note: S0 and S1 were the same picture (a rigged mechanical device spitting a pile of identical purple sites) and S1 was the longest scene sitting on the retention cliff. Fix: give each ONE job. S0 owns the OUTPUT (a wall of pixel-identical clones = "they're all the same"). S1 owns the CAUSE (the rigged DECISION). A slot machine is the perfect object for "a choice that looks random but is fixed to always land the same," which a copier cannot say. We stage ONLY the three reels locking to PURPLE·INTER·CENTERED and DELETE S1's clone-payout-pile entirely, so it never re-shows S0. Distinct base object (copier vs bandit), distinct verb (print vs pull-and-lock). We also dropped the Pam "same picture" gag (already in S0) and the TASTE gauge (reserved for S2) to spread the motifs thinner per the notes. Runtime trimmed from 7.85s to ~5.6s; the ~2s goes to S6.
- **Proof / real UI:** The three reel symbols are the REAL, recognizable fingerprints of AI-vibe-coded sites, shown as literal slot icons so the scene reads as a diagnosis, not decoration: (1) an actual purple-to-violet gradient swatch, (2) the real Inter "Aa" glyph, (3) a true wireframe of a centered headline stack + one rounded pill button. A stranger who has seen ten AI sites recognizes all three instantly. That recognition IS the proof of the claim.
- **Escalation:** Pull 1: coin in, KA-CHUNK lever, reels blur then slam-lock purple / Inter / centered, RIGGED bulbs flash. Beat. Pull 2: he swaps in a bigger, fancier prompt-coin (visibly "a better prompt"), yanks harder, reels spin longer... and slam to the exact same three symbols. The payout window reads identical both times. Optionally a fast third micro-pull, same result. Escalation is "trying harder changes nothing," ending on him out of coins with the rigged reels frozen.
- **Gag / pop-culture:** Vegas one-armed bandit / rigged casino slot as the base gag, topped with a buzzing neon "LOVABOLT" marquee (a legally-safe knockoff of the purple v0 / Lovable / Bolt AI-builder look) and a flat losing-buzzer on each identical pull. The joke: the "jackpot" light celebrates while paying out the same generic slop every single time.
- **Sprite costume:** Claude as a wide-eyed Vegas high-roller / gambler: green dealer visor on the head-top, a loud gambler's blazer, a bucket of "prompt" coins clutched in one arm, the other arm stretched up yanking the oversized lever. Base rounded Claude silhouette + face kept intact; costume = visor (head-top) + blazer / coin-bucket (body props) only. His hopeful-then-defeated expression sells "not my fault."
- **Transition + SFX:** SFX: coin clink drop, mechanical KA-CHUNK lever pull, reels rattling click-click-click then a hard triple CLUNK as each locks, a flat losing buzzer, a rigged-bulb electric buzz, ambient casino murmur + a low slot-jingle bed. Motion: reels blur-spin with motion streaks, snap-lock with a small screen-shake per reel. OUT-transition into S2: the reels freeze, the RIGGED bulbs hold, and a single electric spark leaps off the chrome toward an off-panel armor rack, hard-cutting to S2's Iron-Man suit-up.
- **Mute check:** Sound off, under 2s: you see a slot machine's three reels lock onto a purple gradient, an "Aa", and a centered one-button layout, with a red RIGGED light glowing. It instantly reads "this machine always lands the same generic look."
- **Hook into next:** The gambler is out of coins, staring at reels that lock identical no matter what he feeds them. He realizes you cannot out-pull a rigged machine, you have to UPGRADE it. A spark jumps off the bandit toward an armor rack, opening the "but then... you suit it up with real taste" loop that S2 (Iron-Man suit-up) pays off.
- **Hook variants:** Out of coins, he glares at the rigged reels: the pull was never the problem, the machine is. Cut to the armor rack. | The jackpot bell rings on the SAME three symbols again. He needs to stop gambling and give the machine taste. Spark leaps to S2. | He yanks a fancier prompt-coin, reels slam identical, RIGGED light blazes. There has to be a way to rig it back... suit up.
