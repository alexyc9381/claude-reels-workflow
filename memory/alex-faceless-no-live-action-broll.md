> “can you not do like real video brolls? like dont have those and please push this learning to the github repo and remember it”

This supersedes the earlier request in the same project to include real UGC/video B-roll. The filmed typing, handwriting, laptop, study, frustrated-worker and paper-crumpling inserts are rejected for this reel. Previous delivery and technical checks did not establish creative approval.

## Standing default for this lane

- Do not include live-action, stock or UGC B-roll in NoCodeAlex faceless reels unless Alex explicitly requests an exception in a later brief. Do not reintroduce it to improve motion scores or to solve a weak animated concept.
- Replace filmed inserts with authored, narration-matched animation: recognizable original Claude sprites performing purposeful actions, expressive reactions, detailed sets and useful outcomes. Preserve hierarchy, anticipation, contact and follow-through.
- Removing footage is not permission to fall back to repetitive screens, rectangles, lines or static cards. Keep a distinct meaningful event for each beat.
- Keep authentic product logos where applicable. This feedback is about filmed B-roll; it does not ban logos, useful product UI, or separate explicitly requested talking-head formats. Do not extend this rule to unrelated projects or the face-camera ChatGPT lane.
- Before delivery, inspect the full scene list and rendered timeline for leftover footage, including footage hidden in shared helpers or short cutaways. Check replacement animation and its sound cues together.

Read this before using older examples in the craft docs that recommend real B-roll. Those historical measurements are not authorization to include footage under this updated default.
