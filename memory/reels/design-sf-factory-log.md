## Build lessons (reusable)
- ⛔⛔ **NAME COLLISION, again** (4th time burned): my new `words_design.json` silently overwrote the reel-16 DESIGN reel's OWN `words_design.json` (which has a `.line` field mine lacked) → its module-scope `CHUNKS` IIFE threw `Cannot read properties of undefined (reading 'length')` at BUNDLE LOAD, breaking EVERY render in the project, not just mine. Fixed: `git checkout` restored the original (it was in the baseline commit), my data → `words_designtools.json`. **A `words_<keyword>.json` name can already be taken by an OLDER reel with the same keyword — grep `import.*words_<kw>` before writing.** VO file was safe (old reel uses `vo_design.wav`, mine `design_vo.wav`). See [[reel-asset-name-collisions]].
- **VO clip fix**: raw `design_vo.wav` already peaked 0.997 (but rms only 0.082 = quiet-with-spikes), so the baked ×1.42 gain hard-clipped to 1.42. Fixed by pre-limiting in numpy (`y=tanh(x*2.2)`, normalize peak 0.88) → `design_vo_lim.wav` at gain 1.0: peak 0.88, rms 0.141 (louder AND clean). Then trimmed all SFX ~30% + bed 0.11→0.085. Final mix: peak 0.79, 0% clipping, VO dominant, buzzer climax loudest (rms 0.165). Bundled ffmpeg has NO raw-pcm muxer — extract to `.wav` (pcm_s16le + wav muxer are enabled) to measure.
- **Chiptune bed** synthesized in numpy (`designsf_chiptune.wav`, 31s): square bass + pulse arp on C-G-Am-F, noise kick/hat, 138bpm, soft-limited, onset at 0s (no fade-in intro). Per [[soundtrack-onset-at-zero]].
- **Output-screen prop** was the single biggest visual win — killed the empty-floor dead space AND made it unmistakably about DESIGN tools (each screen telegraphs the verdict). Fighter's fist points at its own output = reads as presenting/attacking it.
- SFX at ROOT times (scenes are conditional-rendered w/ lf=frame-Lf[i], NOT Sequence-wrapped) → absolute at = Lc[i]+localOffset. Mario chiptune SFX (m_powerup/m_stomp/m_1up/m_coin) + crowd_cheer fit the arcade theme perfectly.
