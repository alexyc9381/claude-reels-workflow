⛔⛔ Reel 124's hook had a mask. I refined it four times — size, then colour, then timing, then
material — each round treating *"still not interesting"* as a rendering problem. Round five:

> *"at 4 seconds why ist here that thing on the screen like that mask thing lik ei dont like the
> mask concept even i the very hook part like please remove nad replace."*

**Four rounds spent tuning a thing that should not have existed.**

⭐⭐ **THE RULE: the second time a note lands on the same object, stop tuning and replace the
concept.** A repeated note is not "not enough of it" — it is "not this."

**Why:** each refinement round reads as agreement ("he wants it better"), so the same wrong object
survives review after review while the budget burns. The signal that distinguishes *tune* from
*replace* is not the wording of the note — it is that the note keeps landing on the **same noun**.

**How to apply:**
- Track which noun each rejection names. Same noun twice → new concept, not a new coat of paint.
- A rejected concept is never adjusted: two hook worlds on 124 (a tailor's shop, a portrait wall)
  were rejected outright. [[feedback_dressing_the_words_is_not_redoing_it]]
- ⭐ **When Alex names reference reels — OX, UNLAZY, BOSS — he means a CONCEPT CLASS, not a look.**
  What those share is *a body doing physical work against a load*. Copying palette or camera answers
  nothing; build an event with weight in it.
