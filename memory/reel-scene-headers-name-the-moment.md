Every scene header must name **what the VO is saying at that exact moment** — the
command, the feature, the claim. Never the set, the room, or the theme.

Reel 78 LIMITS shipped a round with headers reading `Cut the File`, `Refinement`,
`Corner Office`, `The Whole Wall`, `Ten Fewer`. Alex: *"the headers for each scene
make no sense like 'corner office' etc - it should be more related to Claude about
what I'm speaking about at that exact moment."*

They became:

| scene | was | now |
|---|---|---|
| S1 | FIX 01 · Cut the File | FIX 01 · `/compact` |
| S2 | FIX 01 · Refinement | WHAT /COMPACT DOES · Keeps what matters |
| S3 | FIX 02 · Corner Office | FIX 02 · `/model opusplan` |
| S4 | FIX 03 · The Whole Wall | FIX 03 · `ultrathink` |
| S5 | AND SO · Ten Fewer | THE RESULT · 10 fewer messages |

**Why:** the theme is the *set dressing*, and a header is the one piece of chrome a
muted viewer reads. Spending it on a Severance in-joke tells them nothing about
Claude — it makes a tutorial look like a mood piece. A header naming the literal
command doubles as the screenshot the viewer saves.

**How to apply:** write the header straight off the VO line for that scene before you
name the set. When the line names a command, the header IS the command — and set it
in the **terminal typeface, lowercase, clay** (`SceneHeader … code`), not the serif
display face; a command rendered in a serif reads as a theme, not as a string you
type. Same test for any label a scene puts on screen: could a viewer who muted the
video tell which Claude feature this scene is about? Related: [[reel-hook-header]],
[[gate-the-how-in-scripts]], [[reel-draw-dont-stack]].
