The theme has to be **recognizable AND about the thing being discussed**. Both. A theme
that is merely interesting, with no line back to the subject, loses the viewer faster than
having no theme at all, because now they are watching something they cannot place.

Reel 78 was first built as a Mad Max: Fury Road knockoff. Alex: *"the animation is far too
different from what is being spoken. Like there's cars and stuff, but we're talking about
Claude and stuff like that. So we need to make it more aligned with what we're talking
about or else the user is not gonna be interested."*

**Why:** a viewer decides in about a second whether a video is for them, and they decide it
from the picture. If the picture says "car chase" while the audio says "usage limits", the
theme is actively working against the hook. Recognisability is only half the job; the theme
also has to make the subject *legible at a glance*.

## The test: point at every element and name what it IS

Rebuilt as a Severance knockoff, which passes because every element maps:

| on screen | what it actually is |
|---|---|
| the pod of identical refiners | the model |
| the wall of filing cabinets | your conversation history |
| ALL of it re-read because ONE slip arrived | the waste the VO is describing |
| the split-flap USAGE board | your usage limit |
| the summary card that survives the purge | what `/compact` keeps |

Fury Road failed the same test instantly: the cars were not anything. They were a costume.

**How to apply:** before building, write the mapping table. One row per major element, and
each row must name a real part of the subject. If a row's right-hand column is empty, or
reads "it just looks cool", that element is decoration and the theme is probably wrong.
Aim for **recognizable + mapped**, never one at the expense of the other.

Corollary that also came out of this reel: put the literal thing on screen too. Real
Claude Code UI, the actual command being spoken, the real product names. The theme carries
the *feeling*; the literal layer carries the *information*. Related:

[[creator-lane-ceilings]].
