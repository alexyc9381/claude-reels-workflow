Claude starts every conversation from zero. That's not a bug, it's how the context window works, and it's why you keep re-pasting the same background before you can ask the real question. You pay for those tokens every single time.

The fix is a wrap up skill. At the end of a session Claude writes a structured summary of what happened, and that summary lives in a NotebookLM notebook you keep forever. Next session it reads back only the part it needs.

1. Give Claude somewhere to write. One folder, one index file. That's the whole storage layer.

2. Add the skill. A skill is just a markdown file with front matter, and the description is the only thing Claude sees before deciding to load it. Write it as a trigger, not a title.

3. Save decisions, not dialogue. This is the part almost everyone gets wrong. A transcript is the worst possible thing to store, because the useful facts are buried in conversation you already paid for once.

The part nobody mentions: NotebookLM has no public write API. Nothing pushes a file into a notebook for you automatically. The skill produces a clean file in a folder you control, and getting that folder in is a one time setup, either Google Drive sync or a five second upload. Anyone telling you it's fully automatic hasn't tried it.
