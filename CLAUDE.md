# CLAUDE.md — the map for the next agent

You're in **claude-reels-workflow**: the code + memory "brain" for an AI/Claude Instagram-reel production
system. This file orients you. Read it, then jump to the subsystem your task lives in — don't read the whole
repo.

> **Two things to do before anything else:**
> 1. **Read [`memory/MEMORY.md`](memory/MEMORY.md).** It is the loaded-every-session index of hard-won rules
>    (⛔ = a rule that has burned someone). Most mistakes here are already written down there.
> 2. **This repo is code + text only.** Heavy media (voiceovers, music, finished reels, SFX, renders) is
>    gitignored and lives in Google Drive `My Drive / Claude Reels`. A reel with a factory log but no code
>    in-repo is normal — the code is in Drive or the sibling `matchtern-longform` project.

## Setup

```bash
cd video && npm install     # Remotion + React (the reel project)
cd ../tools && npm install  # ffmpeg-static + ffprobe-static
pip3 install --user faster-whisper   # transcription (playbook §3.3)
```
Open in **Claude Code with `ultracode` on**. To render an existing reel, restore its media from the Drive zip
first (see [`README.md`](README.md)). New reels record fresh VOs, so no old media needed.
