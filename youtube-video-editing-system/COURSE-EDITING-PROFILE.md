# Course editing profile

Use for modules and follow-along lessons where comprehension matters more than maximum cut density.

## Assembly

- Begin with the shared voice-driven EDL, then restore or retain pauses that let a learner complete a step.
- Default to the core 0.50s gap rule only for the first assembly. Review pace by section; a sustained 199-204 wpm cut is usually too relentless for a build-along lesson.
- Prefer about 0.35s of breathing room after approved sentence or step endings. Never add it inside a phrase.
- End modules when a task is complete or on an explicit transition sentence, never merely because a target runtime was reached.

## Screen treatment

- The screen is the lesson. Keep the real UI large enough to read.
- Use reviewed 1.4-1.8x focus crops for settings, values, menus, and small text.
- Give each zoom a declared target. Do not follow generic pixel motion automatically.
- Measure and remove recording chrome only when it does not contain instructional content.

## Course overlays

- `spec`: repeats a value the viewer must copy.
- `step`: shows current progress through a known process.
- `tool`: identifies the app after a switch.
- `waited`: discloses a removed generation or loading wait.
- Module title cards are allowed between modules, not between every small beat.

## Gates

- Every removed silent/high-motion span was watched.
- Captions were corrected, rendered after framing, and exported as SRT.
- Module captions start at each module's zero.
- A privacy sweep covers both pixels and speech.
- The final acoustic marker sweep is clean.
