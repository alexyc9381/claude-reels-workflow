# Approved example and current direction

Read [CURRENT-DIRECTION.md](CURRENT-DIRECTION.md) before authoring. This file separates approval from later requests.

Alex approved the short **DispatchExplainerSound v11** study on September 10, 2026. Its reusable strengths are hierarchy, substantial moving payloads, original Claude actors, purposeful overlapping jobs, tactile contact and readable glass. It is a reference example, not a requirement to repeat its dispatch scene or seven-second duration.

The later full-film requests explicitly supersede parts of that study:

- Manrope sans-serif, not its Fraunces display face.
- Mature/professional environments, not toy-like machines.
- White optical glass only; cream/orange with supporting teal/blue/mint/gold.
- Existing courier, archivist and operator outfits allowed following the later explicit request.
- Symmetric eyes, purposeful actions, no hard-stop landings.
- No replayed whole scenes; each beat has a beginning, action and payoff.
- No CGI companion in the active Higgsfield film, despite earlier requests to include it.
- Dialogue, screen legibility and evidence take priority over motion density.

**V9 is a review revision, not newly approved animation or a publication-ready film.** See [the project record](projects/higgsfield-replacement/REVISION-V9.md). [The complete pre-v9 direction](history/ANIMATION-DIRECTION-PRE-V9.md) is retained as historical evidence.
